## lan disk 1.0.0

单 exe 的 Windows 局域网文件服务器：Go 后端 + 内嵌 Vue 3 前端 + 浏览器端 FileViewer 预览。

### 亮点

- **部署只要一个文件**：`land.exe` ↗ `install` 注册 Windows 服务并开机自启；运行期只有 `land.exe` + `land.db`，配置、账号、备注、日志、回收站元数据全在库里。
- **文件点开就能看**：PDF / Word / Excel / PPT / OFD / 图片 / 音视频 / 代码 / Markdown / 压缩包 / CAD(DWG·DXF) / 3D 模型，Worker/WASM/字体全部同源自托管，**服务端零转码、断网可用**。
- **权限模型简单可追溯**：单管理员（用户名默认 `admin`，可改名，登录长期有效）+ 匿名只读；写操作按目录授权，删除/改名/移动/回收站仅管理员；无权限目录对匿名完全隐藏。
- **每个操作都有账**：全量审计日志（含 IP 与反查主机名）、按时间/IP/操作筛选、CSV 导出、90 天保留；IP 白/黑名单带命中计数，限速与并发上限后台即时生效。
- **回收站**：删除进共享内 `.land-trash`，可恢复（同名冲突需确认覆盖），保留期可配。

### 安装

```powershell
land.exe install          # 管理员执行：注册服务 + 开机自启
land.exe reset-password   # 取管理员口令（不落任何文件）
# 浏览器打开 http://<本机局域网 IP>  → 登录 → 新建共享
```

默认端口 80，被占用时启动信息会报出占用进程；换端口：`land.exe config set port 8080`。

### 已知边界

- 共享内指向其他卷的 Junction 会被安全策略拒绝（挂载点登记尚未提供入口）。
- IP 规则的 CSV 导入/导出未实现（主机名的已实现）。
- DWG 引用了未内嵌的 `ltypeshp.shx` 时，复杂线型按虚线/点线近似渲染（图纸数据提示，非预览失败）。
- 完整清单见仓库 `architecture.md#已知缺口`。
