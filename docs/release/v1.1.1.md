## lan disk 1.1.1

两件小事：**公告改成页头单行滚动**，以及**在 README 声明本项目由 AI 生成**。

### 公告

- 公告不再是页头下方的独立公告块，而是**与登录/账号按钮同一行**：左侧一个通知图标 + 单行文本，超出宽度时以跑马灯方式循环滚动，悬停暂停，`prefers-reduced-motion` 下不滚动。
- 文本放得下时**不滚动**（也不会出现跑马灯为无缝循环而复制出来的第二份文字）。
- 公告改为**纯文本**：后台输入框变成单行（200 字上限），保存时换行/制表/控制字符会被压成空格，**不再渲染 HTML**（旧数据里的 HTML 标签会按字面显示，编辑一次即可清除）。
- 页头品牌区不再换行，窄窗口下公告自动让位。

### AI 生成声明

README 顶部加了显著提示、底部新增「🤖 AI 生成声明」章节并加徽章：代码、文档与发布产物均由 AI 编程助手（Pi / ThinkRail）在维护者的需求与逐轮评审下生成；维护者负责方向与验收；AI 输出不保证无缺陷，使用前请自行审查，项目按 MIT「按原样」提供。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → Ctrl+F5。`landisk.db` 不动。
