## lan disk 1.1.0

**虚拟根目录**：所有共享目录都挂在同一个根下，不再有单独的首页。

### 变化

- `/` 就是文件站本身：根目录里每个共享目录显示为一个文件夹（名称 + 挂载路径），双击或点图标进入；行末仍可“打包下载整个共享”。
- 进入共享后是原来的文件列表（文件名 / 备注 / 操作 / 大小 / 修改时间），面包屑改成 **根目录 / 共享名 / 子目录…**，随时可以点上上级回到虚拟根。
- 根目录上不显示上传/新建目录/搜索（它们需要具体目录），进入共享后按原权限出现。
- 页脚版本号改为读取实际运行的构建版本（`/api/site` 新增 `version`），不再硬编码。
- 删除了独立首页组件，站点公告、登录状态、管理员菜单保持不变。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → 浏览器 Ctrl+F5。`landisk.db` 与共享目录不动。
