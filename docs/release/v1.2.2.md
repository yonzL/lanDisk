## lan disk 1.2.2

两个体验缺陷：首次登录改密要重复输入旧口令、登录/退出后页面不刷新。

### 1. 首次设置口令不再要求当前口令

- 首启（或 `reset-password` 之后）第一次登录时，会话就是用那个临时口令建立的，服务端此时**不再校验"当前口令"**，页面上也不显示该输入框。
- 之后的每次修改仍需当前口令（服务端照旧校验，测试覆盖：清掉 `must_change` 后再提交无当前口令 → 401）。
- 页面标题相应改为「首次登录：请设置用户名与口令」，并提示"不用再输一遍初始口令"。

### 2. 登录 / 退出后页面即时刷新

- 页头与管理员菜单本来就是响应式的，但**目录内容里的可写按钮、备注入口、可见共享都是服务端按访问者算的**，之前只有前端状态变了、数据还是上一个身份的。
- 现在浏览页监听 `session.authenticated`：登录或退出后自动重新拉取当前目录，无需手动 F5。

实测（无头 Edge 走真实表单）：

```
匿名 /s/1 → toolbar: [搜索, 刷新, 打包下载], 无账号菜单
登录后   → 页头出现账号菜单（admin）
在 /s/1 点「退出登录」→ 跳转 /，账号菜单消失、出现「登录」，toolbar 只剩 [刷新]
```

首次改密的实测（curl）：登录返回 `must_change:true` → `POST /api/password` 只带 `new_password` → 200；再次提交不带当前口令 → 401。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → Ctrl+F5。`landisk.db` 不动。
