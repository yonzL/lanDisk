## lan disk 1.1.2

**修复文件名以 `#` 开头（或含 `?`）的视频/文档预览**：原来会被当成 `.bin`，提示"未装配 Binary Inspector renderer"。

### 原因

预览器把传入的文件名当 URL 解析（`normalizeFilename` 会按 `#` / `?` 截断）。像
`#知识分享官#【可能是全宇宙最通俗易懂的通信课】-移动通信基础2.mp4`
这样以 `#` 开头的名字，截断后变空，回落到默认名 `preview.bin` → 扩展名 `bin` → 走二进制检查器，于是报"未装配 Binary Inspector"。

### 修复

交给预览器之前，把文件名里的 `#`、`?` 百分号编码（`escapeViewerName`）。预览器再 `decodeURIComponent` 还原，显示名不变、扩展名正确，**视频/PDF/Office 等正常进入对应链路**。

实测：同一文件修复后不再出现 `.bin` 提示，进入媒体链路（我用的测试文件是伪造的 12 字节 mp4，所以显示的是解码失败 `DEMUXER_ERROR_COULD_NOT_OPEN`——真实视频可正常播放）。

新增回归脚本 `web/scripts/check-viewer-name.mjs`，直接对 `@file-viewer/core` 的 `normalizeFilename` / `getExtension` 断言"编码后名字不变、扩展名正确、原样名字确实会变 `preview.bin`"。

### 顺带

- 预览页自身的「下载」链接与预览器内置下载按钮会同时出现；前者在无法预览时仍可用，故保留。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → Ctrl+F5。`landisk.db` 不动。
