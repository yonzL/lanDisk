## lan disk 1.0.2

两个命名对齐：可执行文件叫 **`lanDisk.exe`**，数据文件叫 **`landisk.db`**（原 `land.db`）。

### 变更

- 可执行文件：`land.exe` → **`lanDisk.exe`**（1.0.1 起）。
- 数据文件：`land.db` → **`landisk.db`**（本版）。
- **自动迁移**：首次启动时若同目录只有旧的 `land.db`（含 `-wal` / `-shm`），程序会把它连同副文件一起改名为 `landisk.db`，无需手工操作；两者都存在时以 `landisk.db` 为准。
- 服务名（`LandDisk`）、端口、共享目录、账号、备注、日志、回收站内容都不受影响。

### 升级步骤

```powershell
# 1. 停掉旧服务（如果装过）
land.exe uninstall

# 2. 用新文件替换旧 exe：把 lanDisk.exe 放进同一目录（land.db 也在这里）
lanDisk.exe install

# 3. 口令不变，直接登录；数据库已被自动改名为 landisk.db
```

只想先确认迁移是否正确：先跑一次 `lanDisk.exe version`，再启动服务，目录里应出现 `landisk.db`。
