## lan disk 1.3.0

**IE11 兼容模式**：现场只有 IE11 的机器现在也能浏览、下载、上传文件。

### 为什么需要单独的页面

IE11 跑不了现在的界面：Vue 3 依赖 `Proxy` 与 ES modules，FileViewer 依赖 Worker/WASM，IE11 全都没有——打开就是白屏。"把整套代码降级编译到 ES5" 既不可行也保不住预览，所以做成**第二套渲染路径**。

### 行为

- 服务端按 User-Agent（`Trident/7.0`、`MSIE `）自动切换：IE11 打开同一地址进入**兼容模式**，现代浏览器行为完全不变。
- 兼容模式是**纯服务端渲染的 HTML**，零 JavaScript，只用表格、链接与普通表单：
  - 共享目录列表 → 目录浏览（文件名 / 备注 / 大小 / 修改时间）
  - 下载文件（走既有的 `/raw`，Attachment）
  - 上传文件（multipart 流式写入目标目录，落盘后 rename）、新建文件夹（仅在开启写权限的目录显示表单）
- 兼容模式**只服务匿名访问**：需要登录的管理功能（共享配置、日志、回收站、备注编辑）请用现代浏览器。
- **没有在线预览**：页面底部明确提示"需要预览请用 Chrome / Edge 打开同一地址"；从完整界面的预览链接（`/s/{id}/preview/...`）进入时会落到所在目录，方便直接下载。
- `?modern=1` 可在 IE 中强制尝试完整界面（便携 Chromium 或排查用）。

### 实测

- IE UA 打开 `/` → `根目录 · lan disk` 的兼容页（含共享列表），不带 `#app` 容器。
- IE UA 打开 `/lite/s/1` → 目录表格（`图纸`、`说明.txt`）+「上传文件」「新建文件夹」表单 + 兼容模式提示。
- IE UA 用 multipart 上传 → `303` 跳回目录，文件落盘；只读共享上传 → `403`，磁盘上不产生文件。
- 现代 UA 打开 `/` → 仍是完整 SPA（页面不含兼容模式字样）。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install`；IE 端直接刷新即可。`landisk.db` 不动。
