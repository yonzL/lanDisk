## lan disk 1.0.1

**可执行文件更名为 `lanDisk.exe`**（原 `land.exe`），与项目名一致；功能与 1.0.0 相同。

### 变更

- 编译产物、帮助文本、错误提示、README 与架构文档统一使用 **`lanDisk.exe`**。
- 数据文件名保持 `land.db` 不变——升级时直接用新的 `lanDisk.exe` 覆盖旧 exe 即可，**不需要迁移数据**。
- 已安装旧服务的机器：先 `land.exe uninstall`，再用 `lanDisk.exe install` 重新注册（服务名 `LandDisk` 不变）。
- `reset-password` / `config get|set` / `version` 用法不变，仅命令名变化。

### 安装

```powershell
lanDisk.exe install          # 管理员执行：注册服务 + 开机自启
lanDisk.exe reset-password   # 取管理员口令（不落任何文件）
# 浏览器打开 http://<本机局域网 IP>  → 登录 → 新建共享
```
