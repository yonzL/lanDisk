## lan disk 1.2.0

**图片缩略图**：列表里图片文件直接显示小缩略图，不用点开预览才知道是哪张。

### 行为

- 图片（jpg / jpeg / png / gif / bmp / webp）在「文件」列显示 **36×36 圆角缩略图**（裁切填充），其他类型仍是文件类型图标。
- 缩略图由服务端按需生成：缩到 96 px 长边，不放大；含透明通道输出 PNG，否则 JPEG（q82）。
- **内存 LRU 缓存**（512 条 / 64 MB），键包含文件 mtime 与大小——文件一改缩略图即更新；缓存不落盘，数据目录仍是 `lanDisk.exe` + `landisk.db`。
- 解码最多 4 个并发，浏览大图目录不会把 CPU 打满；同一张图的并发请求只渲染一次。
- 浏览器侧 `ETag` + 1 小时缓存 + `loading="lazy"`，只请求看得见的行；渲染失败或格式不支持时回退为文件类型图标。

### 冒烟

本地用三张 1600×900 / 900×1600 / 800×600 的 PNG 验证：列表显示三张不同缩略图，文本文件仍是图标；`/thumb` 返回 `200 image/png`（305 B，源图 39 KB）。`go test ./internal/thumbs` 覆盖缩放比例、透明转 PNG、非图片拒绝、缓存命中与键随文件变化。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → Ctrl+F5。`landisk.db` 不动。
