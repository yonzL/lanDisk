## lan disk 1.2.1

**缩略图缓存改到系统临时目录**，进程内不再保留缩略图数据。

### 变化

- 缓存位置：`%TEMP%\lanDisk-thumbs\`（服务运行时是服务账号的 temp 目录，例如 `C:\Windows\Temp`）。程序目录仍然只有 `lanDisk.exe` + `landisk.db`。
- **只落磁盘**：移除了原来的内存 LRU，缩略图不再占用进程堆；每次命中直接读文件。
- 文件名为 `sha256(绝对路径|mtime|size|px)`，文件一改就换新文件；写入用"临时文件 + rename"，并发读取不会读到半个文件。
- **自清理**：启动时与每 64 次写入扫一次，删除 7 天以上的条目；目录超过 512 MB 时按最旧优先删到限额以下。Windows 自己清临时目录也只是让缓存失效一次，下次自动重建。
- 可用环境变量 `LAND_THUMB_CACHE` 指定别的目录（测试/迁移用）。
- 浏览器侧行为不变：`ETag` + 1 小时缓存 + `loading="lazy"`，非图片 404 回退图标。

### 实测

同一张图连续请求：首次 ~49 ms（解码并写盘），之后 ~2 ms（磁盘命中）；重启服务后请求已缓存的图仍然 ~2 ms（证明缓存跨进程有效）。缓存目录里能看到 305 B 的 PNG，源图 39 KB。

### 升级

覆盖 `lanDisk.exe` → `lanDisk.exe uninstall` / `install` → Ctrl+F5。`landisk.db` 不动；旧的内存缓存随进程退出自然消失，无需清理。
